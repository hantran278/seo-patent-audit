Audit backlink: thả file Semrush → Backlink Analytics → Referring Domains (hoặc Backlinks) → báo cáo có tab Backlink: DISAVOW / REVIEW / RECHECK / KEEP, cụm IP, domain mới theo tháng, tải disavow.txt. Thả thêm file backlink của đối thủ để xem link gap.
